# Hachimi Survival Unity 工程

## 环境

- Unity 6000.3.24f1
- URP 2D、Input System、uGUI

## 运行

1. 用 Unity Hub 打开本目录。
2. 打开 `Assets/Hachimi/Scenes/R01_Combat.unity`。
3. 点击 Play。

操作：WASD 移动，Space 猫扑，Q 哈气，R 重置，Esc 暂停；F1 显示调试面板，F2 切换单猫／混编，F3 测试普通击退，F4 切换 Q 满／空，F5 切换猫扑就绪／冷却，Tab 切换自动攻击，1／2 切换选敌模式。

当前视觉和音频使用程序占位；最终资源分别接入 `Assets/Art/R01/` 和 `Assets/Audio/R01/`。原始制作文件放在仓库根目录的 `SourceAssets/`。
