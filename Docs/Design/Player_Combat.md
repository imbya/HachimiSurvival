## 操作、反制与自动选敌

### 三种手段的分工

| 手段 | 首轮规则 | 玩家获得什么 |
| --- | --- | --- |
| 普通移动／WASD | 持续移动，可穿过敌人身体但仍可能承受有效攻击 | 诱导锁向、形成穿透角度、接近后排 |
| 猫扑／Space | 沿移动方向短距离位移；静止时用最后移动方向；持续 0.18 秒，冷却 3 秒 | 离开危险区，改变输出位置 |
| 哈气／Q | 满 100 能量释放；立即震退杂兵，打断范围内可打断的敌人；强化 6 秒，攻速 +30%、射程 +15% | 取消眼前威胁，留下反攻 |
| 普通击退 | 可受击退阶段只改变间距，不取消招式或重置计时；战术敌人最终锁向与攻击有效阶段免普通位移击退 | 维持距离，不代替 Q 打断，也不移动已确定的危险轨迹 |

猫扑首轮采用全程 0.18 秒免伤，替代旧版的“0.18 秒动作、前 0.12 秒免伤”，减少初次试玩的判断歧义。3 秒冷却暂不调整；这两项仍需操作验证。

哈气只在对峙猫的观察蓄力（前 0.3 秒）和最终锁向预警（后 0.5 秒）取消即将发生的扑击；已经进入扑击有效段时不能打断。成功后敌猫在原地进入 1.2 秒“已老实”窗口，期间承伤增加 25%。只让视觉子节点缩身，不把目标实际推离近战射程。Q 本身不提供免伤，不能靠扑击已经撞上后按 Q 取消这次伤害。

其他战术敌人同样只在出招预警状态允许 Q 打断；入场、普通移动、攻击有效段、恢复、已老实和死亡状态不触发新的打断窗口。已经发出的弹丸不因发射者被 Q 命中而消失。Boss 首版两种攻击均作为不可打断重招，用不同预警标记说明；Q 仍可强化自身。最终战有意识地侧重移动、猫扑与强化时机，不宣称它完整检验了普通波的打断玩法。

成功打断后，老吴叫下一轮攻击的剩余等待最多为 0.15 秒；已经发出的攻击不瞬间改向。这样反攻收益能在窗口内兑现，而不是只给一个字幕。

### 自动攻击怎样体现玩家意图

每把需要选敌的武器在开始一轮攻击时，从自身射程内依次选择：

1. 最近一次被玩家哈气打断、仍在“已老实”窗口内的目标；多只时取最近者。
2. 玩家最后移动方向前方 120° 内的战术敌人；优先保留仍符合这一条件的当前目标。
3. 仍有效且本次选定未满 0.35 秒的原目标。
4. 最近的可攻击敌人。

玩家可以通过走近、绕侧和改变移动方向影响下一轮攻击。优先目标必须在该武器射程内，不能为追打它而让所有武器停止攻击。开发显示中标出目标与选中原因，方便判断规则是否符合直觉。

老吴叫使用约 0.12 秒张嘴动作，在发射前锁定方向，随后两道声波沿同一方向发出。南北绿豆一轮三发也锁定同一方向。目标在锁定前死亡或离开范围则重新选敌；锁定后照原方向完成这一轮。猫爪面向所选目标挥击，OIIA 环绕和拍地板范围攻击不强行选单体目标。

这一套选敌规则是待测候选，移动方向也可能表示撤退，不能直接视为瞄准意图。第一场景提供简化候选作对照：“哈气打断目标 → 保留仍在射程内的有效当前目标 → 最近目标”，取消方向优先和短时保留上限。用相同配置比较撤退、横向绕行、短促变向，不预先选定胜者。若玩家经常接近对峙猫却打不到它，先调整选敌、攻击周期和形状，再考虑增加手动瞄准。

### 首次教学的十几秒

教学场景显式给予一次满能量哈气，再让第一只对峙猫入场；不依赖自然充能。玩家先看到低密度杂兵被老吴声波穿透，随后看到站姿和箭头预警，再自行选择横移、猫扑或 Q。提示写“Q 哈气：打断叫阵，留在原地反攻”。

教学不冻结战斗等玩家按 Q，也不给敌人强制不死；玩家直接击杀同样有效。开发场景提供一键重置这一段，方便比较不同操作。正常随机局从零能量开始，教学赠送不带入普通局。

第一场景把玩家移速／碰撞半径、猫扑距离、敌人扑击距离／宽度／速度、Q 半径、武器射程／声波宽度暴露为可调配置。调试显示真实碰撞范围与危险预警，并可切换满 Q／零 Q、猫扑就绪／冷却、两种选敌模式。时间参数沿用本版，空间数值在场景中调整，重点看侧移是否够用、猫扑是否真正脱险、打断目标是否处于可兑现的攻击范围；不凭时间参数单独宣称反制成立。
