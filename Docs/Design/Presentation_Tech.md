# 表现、AI 资产与技术路线

更新：2026-09-14。依据：原计划 v0.2.1。返回[总体方案](../PROJECT.md)。

这是持续维护的设计参考；当前做哪些内容，以 [plan](../../plan/README.md) 中的任务为准，不要求在 R01 实现本文全部内容。

## 爽快反馈首先要让玩家看得懂

**信息优先级：危险落点和方向／玩家受伤 → 玩家与关键敌人的姿态 → 己方攻击效果 → 鱼干、伤害数字与装饰。**

危险提示保持独立轮廓和辨识颜色，在哈气气浪、老吴声波和金币堆叠时仍然可见。玩家和对峙猫的关键姿态可用描边或局部淡化遮挡物强调。敌人攻击预警不能只依赖颜色或梗人声。

局部反馈先做缩放挤压、嘴耳变化、命中闪白、方向性退让、弹丸拖尾与鱼干弹跳。视觉子节点负责夸张变形，碰撞根节点保持稳定。屏幕震动、闪光、伤害数字密度和梗人声分别可调。

全局命中停顿首轮约 30 毫秒，仅允许：成功哈气打断、拍地板重击命中、精英／Boss 被击杀。使用真实时间跨帧限频，两次至少间隔 350 毫秒；间隔内请求丢弃，不排队、不延长当前停顿。普通暴击和高速连射不触发全局停顿。暂停优先于命中停顿恢复，不能因恢复回调把暂停游戏重新启动。

保留“关闭装饰反馈”开发开关：关闭震屏、装饰粒子、夸张数字，保留全部危险预警、有效攻击和玩家受伤信息。用同一个高攻速、高暴击场景比较，观察完整效果是否提高满足感而损害读招。

商店扣款、装备变化、数字和按钮可用状态在确认购买时立即更新；0.12–0.20 秒的飞入与回弹随后播放。已购卡原位变空或标记已购，不自动把其他卡片补位。按下和释放必须对应同一卡片，单次点击只确认一次购买。可继续操作不必等飞行动画，但不能重复购买已失效卡。

HUD 保留生命、猫扑冷却、Q 能量、波次计时与鱼干。猫扑就绪、Q 满能量各在角色附近闪现一次小提示，不再复制完整常驻状态栏。主按钮仍叫“刷新”“购买”“下一波”，梗文案用于辅助提示。

## AI 美术、音频和 Unity 实现

### 单人资产路线

使用“原创重绘的猫表情贴纸＋简洁地面＋程序动画”：先选定一张圆头橘白猫标准形，再从同一参考生成飞机耳、哈气、站立、舔爪等少量状态。保留外轮廓和表情识别，不追求每只敌人完整逐帧动画。AI 负责候选图和声音，人负责统一轮廓、透明边缘、切片、响度与游戏内可读性。

第一段战斗只需要占位图与极少量正式表情；三波小样预计约 15–25 个可用静态素材，重点是圆头猫、对峙姿态、两武器与口香糖。完整 Demo 暂按 55–70 个静态素材、20–30 个短音效、两条基础配乐估算。数量指最终采用资产，不是生成次数；返修与废稿计入工时。

制作顺序：统一参考图与配色 → 生成动作状态 → 修正透明边缘和尺寸 → 导入实际战斗看缩小后能否辨认 → 再批量做同系列。AI 生成界面底图，文字、按钮和布局在 Unity 中制作，不把文字烘焙进图片。

听觉主题保留哈基米音节、老吴短叫、曼波、叮咚鸡、大狗叫。配乐使用原创旋律与自行生成／录制的音色，既有《蓝莲哈》等作品用于风格参考。原视频、歌曲、具体配音不因作为梗参考而默认进入发布包。实际采用情况记录到[素材使用记录](../References/Asset_Usage_Register.md)。

战斗曲拆为基础伴奏、短人声、强化节奏；商店／结算共用另一条基础曲。先得到可循环伴奏，再补少量短声，不要求一次 AI 生成就获得完整可用分轨。老吴高频攻击不要每发都播完整长嚎，按攻击轮次限频、缩短音节，关键演出再突出。

### 技术选型与三种时间

保留 Unity 6.3 LTS、URP 2D、uGUI／TextMeshPro、Input System；使用数据资产配置武器道具，小型状态机处理敌人，常见对象池处理敌人、弹丸、拾取物与特效。战术决策约每秒 5–10 次，运动和碰撞正常更新。编辑器补丁与包版本按 Unity 项目文件正常记录；不额外冻结合同或制造版本门禁。Unity 官方目前列出 6.3 LTS 支持至 2027 年 12 月。[官方支持页](https://unity.com/releases/unity-6/support)

| 时间来源 | 用途 | 暂停／商店行为 |
| --- | --- | --- |
| 战斗时间 | 波次、攻击、移动、受伤保护、猫扑、哈气、回血与冷却 | 停止推进 |
| 不受战斗缩放影响的时间 | 商店动画、提示、暂停菜单、命中停顿恢复及限频 | 正常运行；但恢复逻辑尊重当前暂停状态 |
| 音频 DSP 时间 | 音乐分层、循环、下一拍的入点 | 音乐按场景淡出或继续，不推进战斗规则 |

Unity 的 `timeScale = 0` 会停止 `FixedUpdate` 与等待 `WaitForSeconds` 的挂起协程，不能用它们负责唤醒自己的命中停顿。[Time.timeScale 文档](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/Time-timeScale.html)

哈气判定、叫声和基础气浪立即发生；只有附加音乐层通过 `AudioSource.PlayScheduled` 按 `AudioSettings.dspTime` 安排入点，不延迟操作等待拍点。[PlayScheduled 文档](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/AudioSource.PlayScheduled.html)

短命中停顿可缓存约 100 毫秒的猫扑／Q 输入；切入商店、暂停或死亡时清除战斗输入缓存，避免恢复后意外释放技能。
