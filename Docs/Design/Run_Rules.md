# 伤害、恢复与局内状态

更新：2026-09-14。依据：原计划 v0.2.1。返回[总体方案](../PROJECT.md)。

这是持续维护的设计参考；当前做哪些内容，以 [plan](../../plan/README.md) 中的任务为准，不要求在 R01 实现本文全部内容。

## 核心规则约定：避免靠等待或碰撞歧义决定胜负

| 情况 | 首轮处理 |
| --- | --- |
| 受伤保护 | 玩家真正受伤后共享 0.5 秒免伤；纸箱盾抵挡一次有效伤害后也给予这段保护。同帧多攻击不会连续扣血 |
| 同一攻击重复命中 | 一次敌人扑击／一枚敌弹最多命中玩家一次；玩家一枚声波对同一敌人一次，两道声波分开计算；OIIA 对同一目标命中间隔至少 0.35 秒；回旋镖去程、回程各一次 |
| 猫扑与碰撞 | 可穿过敌人，不能穿墙；撞墙结束位移但不额外延长免伤。免伤结束仍与有效攻击重叠，下一次有效判定可受伤，不补赠脱离保护 |
| 哈气充能 | 起始实现按实际造成的有效伤害×0.07＋击杀数×1 充能，封顶 100；过量伤害不计，多目标各计，追加攻击正常计。40–60 秒充满只是观察目标，需按实际输出调系数 |
| 强化期与跨波能量 | Q 强化期间不充能；波末清除剩余强化，未消耗能量保留。清场删除敌人不算伤害或击杀，不充能 |
| 口香糖触发 | 战斗中连续 4 秒未受伤、冷却结束且未满血时启动。启动时、随后第 1／2 秒各回复最大生命的 2%，总计最多 6%；显示约 3 秒嚼嘴动作 |
| 口香糖冷却与打断 | 12 秒冷却从首个回血时刻开始。中途受伤立即取消剩余回复，冷却不退款；满血时取消剩余回复，同样不退冷却 |
| 口香糖跨波 | 波末结束正在进行的回复，保留剩余冷却；下一波重新累计无伤时间。商店与暂停均不推进冷却、无伤时间或回血 |
| 波间状态 | 保留当前生命、货币、装备和未消耗 Q 能量；清除临时强化、攻击目标和场上弹丸。下一波武器和猫扑统一就绪，这是明确的波次补给，不随商店等待时长变化 |
| 购物与生命成长 | 进入商店和停留不回复生命；购买厚肚皮时最大生命与当前生命同时增加同样数值，例如 60／100 加 20 后成为 80／120。这是一次付费成长，只随成功购买结算一次。备用纸箱仅在下一波开始生成新盾 |
| 出售 | 返还该武器历次实际支付金额总和的 50%，向下取整；免费初始武器的基础投入为 0，后续付费升级计入 |
| 满槽替换 | 买入新种类武器时，先选择被替换项并预览净花费。一次性完成出售旧武器、扣差价、装备新武器；取消或资金不足时均不改变原状态。升级已有武器不占新槽 |
| 波末清理 | 先结算当前战斗步已有伤害与真实击杀，再检查玩家是否死亡；若仍存活才结算波次。清理剩余敌人不产生击杀收益；回收的只有已掉落货币，另发一次存活奖励 |
| 同时死亡／结束 | 同一步玩家死亡与倒计时结束，死亡优先；与 Boss 同归于尽也判失败。不先切商店再撤回结果 |

受伤、技能、波次和商店状态由明确的先后顺序处理，不另建交易服务或复杂规则平台。对应边界用小场景直接运行验证即可。
