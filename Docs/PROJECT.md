# 总体方案

更新：2026-09-14。当前迭代：[R01 对峙与反攻](../plan/R01/README.md)。

## 游戏方向

类《土豆兄弟》的 Unity 2D 短局生存游戏，以中文互联网猫梗为主题。自动攻击、走位、猫扑与哈气构成战斗；后续通过波间购物形成不同打法。主要面向 Windows 键鼠、简体中文。

核心体验：**敌猫站立叫阵 → 看懂意图 → 诱导扑空、猫扑避开或哈气打断 → 敌猫舔爪／“已老实” → 趁窗口反攻。**

首屏突出圆头耄耋、飞机耳和哈气；老吴叫、应激站立、嚼口香糖与哈基米音乐逐步成为动作和规则。美术采用 AI 原创重绘的表情贴纸和程序动画，音频采用原创短声与旋律。敌人使用可读的状态机，不使用生成式 AI 决策。

## 分工

| 参与者 | 负责 |
| --- | --- |
| 制作人 AI（当前助手） | 方案、任务拆分、目录和状态维护、跨任务协调、review，与用户讨论取舍 |
| 用户 | 体验反馈、方向与偏好决策、分配执行 AI |
| 程序执行 AI | 在任务范围内建工程、实现、运行检查、集成并交付试玩包 |
| 美术／音频执行 AI | 按资源任务生成、整理、检查文件并记录来源；由程序执行者接入工程 |

制作人不默认接管具体代码或批量素材执行，也不自动向其他 AI 任务发送消息。

## 版本节奏

| 迭代 | 目标 | 展开程度 |
| --- | --- | --- |
| R01 | 一个可反复重置的对峙与反攻场景 | 本次唯一展开的任务包 |
| 下一轮 | 依据 R01 review，修手感或加入三波、购物与恢复 | 暂不拆任务 |
| 后续 | 构筑差异、混编，再扩展十波与单阶段 Boss | 仅保留方向 |

R01 保留 1 角色、老吴叫、杂兵猫、对峙猫、猫扑、哈气与必要反馈。商店、鱼干、口香糖恢复、三套构筑和 Boss 都不在本轮。站立对峙是本轮核心猫梗，口香糖留到恢复机制一起加入，避免只有嘴型却误导回血。

完整 Demo 的候选规模仍为 1 主角色、6 武器、11 启用道具、4 类敌人、精英变体与单阶段 Boss；不是本轮必须交付的清单。第二角色、拾取构筑、指挥协作与 Boss 第二阶段继续后移。

## 持续成立的原则

- 猫扑离开危险；Q 在预警期间取消威胁并提供反攻窗口；普通击退不等于打断。
- 战术敌人最终锁向及攻击有效阶段免普通位移击退，预警覆盖与实际攻击一致，正常承伤。
- 危险提示与玩家受伤信息优先于装饰；购买逻辑即时生效、动画随后播放。
- 正式局死亡清空本局成长；只保存设置、最佳战绩，不做局外永久属性树。R01 不需要先实现存档系统。
- 波末全额回收，当前不把主动拾取当战术资源；等待商店不治疗。厚肚皮购买时同步增加当前和最大生命。
- 已明确的机制问题直接修正，平衡与手感争议通过场景对照解决。
