# R01-P02：对峙与反攻

状态：进行中｜执行者：Codex｜依赖：R01-P01｜估时：6–10 小时，可拆两次交付

输入：[本轮场景、参数与状态规则](../README.md)。先用占位资源。美术／音频未完成不阻塞此任务。

## 实现顺序

1. 玩家移动、猫扑、墙体限制、受伤免伤、死亡与 R 重置。实现本轮配置资产，避免把可调数值散落在代码中。
2. 老吴两道穿透声波、单弹单目标只伤一次、有效伤害充能；两种自动选敌模式。发射前锁向，两道同向，不因新目标在中途折转。
3. 杂兵追击与对峙猫状态：入场 → 接近 → 观察 → 最终预警 → 扑击 → 恢复；另有被打断和死亡。预警画出真实攻击走廊，墙前截断，最终锁向后空间数据不变。
4. Q 状态判断、原地反攻窗口、强化与老吴等待缩短；不把 Q 写成全状态眩晕或玩家免伤。扑击开始边界采用同一更新顺序：先处理本步 Q 输入，再推进敌人状态；已进入有效段的扑击不追溯取消，记录这一选择。
5. 两个固定预设、重置、暂停与调试面板。重置销毁旧攻击，清空命中记录、计时、选敌及输入缓存；暂停不推进战斗，恢复不自动释放旧输入。
6. 最小 HUD：生命、Q、猫扑冷却、WASD／Space／Q／R 提示、当前选敌模式。开发显示当前目标和对峙状态即可，不另建遥测系统。

可拆交付：先交移动／伤害／武器可运行版本，再交敌人／Q／调试。仍归同一任务，若确需拆成独立任务由制作人更新清单。

## 完成检查

- 用同一场景实际尝试侧移、猫扑、Q 三种处理，报告成功与失败，不只展示静态箭头。
- 预警与恢复贴身不伤人；扑击单次只扣一次血；死亡敌人不能继续发起攻击。
- 锁向前普通击退可移动敌人，锁向后和扑击中不可；两段预警可 Q 打断，扑出后不可。
- 成功打断后，下一次可启动攻击优先打窗口内目标，实际命中；关闭自动攻击测试状态时不篡改正常生命和伤害。
- 在攻击中、受伤后、Q 强化中、死亡后分别重置，不残留技能、弹丸或敌人。
- 运行检查与必要的小范围规则测试相配合；不以大量模拟代码代替 Unity 场景运行。
