# R01-P03：集成与可运行试玩

状态：待认领｜执行者：—｜依赖：R01-P02；接入已交付的 A01／S01｜估时：2–3 小时

目标：交出用户可以直接打开、反复体验的 R01，附真实运行记录。输入见[本轮说明](../README.md)。

## 实施

1. 将实际资源导入 `Game/Assets/Hachimi/Art/`、`Audio/`，保持原件在 SourceAssets。贴图按脚底基准与统一尺寸设置，视觉节点与碰撞节点分离。
2. 玩家常态／哈气切换；对峙猫常态／站立／恢复切换。用轻微缩放、抖动、闪白表现攻击和命中，不需要额外动画帧；玩家受伤、敌人预警始终清楚。
3. 按 S01 说明接音效，梗人声与必要预警分开控制。资源未到时可以先输出占位试玩，记录缺失文件，不因此声称 A01／S01 已完成；P03 的最终交付仍需接入两项资源，提前试玩不是归档依据。
4. 成功 Q 打断可用约 30 毫秒停顿，真实时间间隔至少 350 毫秒，不排队。普通声波不触发停顿。暂停优先，不能被停顿恢复逻辑解除；保留关闭装饰反馈的对照开关。
5. 生成 Windows x64 构建到 `Builds/R01/Windows/`，附简短操作说明。用户运行完整文件夹，不只复制 exe；无需打开编辑器才能试玩。

## 实测并记录

| 场景 | 检查 |
| --- | --- |
| 单猫，自动攻击暂停 | 侧移、猫扑、预警 Q、扑出后 Q；普通击退在锁向前后是否改变起点；贴近预警／恢复是否误伤 |
| 单猫，自动攻击开启 | Q 后在 1.2 秒窗口内能否实际命中；记录一次打断到首个有效命中的时间 |
| 混编，选敌 A／B | 向后撤退、横移、短促变向，记录具体错误转火实例或未发现问题 |
| 装饰开／关 | 预警是否被遮挡；老吴连续播放是否疲劳，关闭梗声音后仍能辨认预警 |
| 重置／暂停 | Q 强化中、扑击中、死亡后重置；命中停顿时暂停；无残留状态和意外自动释放 |
| 独立构建 | 实际启动并操作，记录机器、分辨率、帧率／帧时间与运行错误；不得拿编辑器运行替代 |

本轮对象很少，不据此宣称达到完整 Demo 的 150 敌人性能目标。自动检查适合伤害次数、状态边界、重置等规则，手感由实际试玩报告；失败项如实保留。
