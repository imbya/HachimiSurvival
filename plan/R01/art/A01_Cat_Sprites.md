# R01-A01：最小猫贴纸资源

状态：待认领｜执行者：—｜依赖：无｜估时：2–4 小时

目标：在小画面中认出圆头猫、飞机耳哈气与站立对峙，区分玩家和敌人。参考[梗库](../../../Docs/References/Chinese_Meme_Reference_v0.1.md)，制作本项目原创重绘，不直接交付视频截图。

## 交付清单

输出到 `SourceAssets/Art/R01/`。先生成一张玩家常态作为统一参考，再派生同系列；不要每张独立换风格。

| 文件 | 内容 |
| --- | --- |
| `player_idle.png` | 橘白圆头、常态、闭嘴 |
| `player_hiss.png` | 同一只猫，飞机耳、张嘴哈气 |
| `enemy_idle.png` | 灰色系对峙猫、常态；靠轮廓和眉眼与玩家区分 |
| `enemy_stand.png` | 同一敌猫直立、抬前爪、叫阵，可看清准备扑击的姿态 |
| `enemy_recover.png` | 同一敌猫低头舔爪，用作恢复与“已老实”姿态 |
| `grunt_idle.png` | 更小、更简单的杂兵猫轮廓 |

## 输出要求

- 统一贴纸插画、粗轮廓、少量阴影，无文字、水印、场景背景和烘焙地面投影。
- 每张 512×512、RGBA 透明 PNG。同角色不同状态保持头部比例与画布中的脚底基准，不靠逐帧动画；朝右，程序可水平翻转。
- 主体约占画布高度 75%，留出耳朵、爪子和受击形变空间。将脚底基准坐标记入说明，程序按相同基准导入；玩家碰撞直径按配置，不按图片透明边自动决定。
- 附 `preview.png`，展示全部素材和约 64 像素高的缩小对照；检查白边、残留背景、缺爪和不同状态跳位。
- 附 `delivery.md`：实际文件、生成工具／模型／日期、提示词与输入素材来源、工具使用条件链接和未核实项。制作人据此更新素材记录。

## 完成检查

实际打开全部 PNG，确认透明通道和小尺寸辨识，不能只交提示词或远程预览链接。不制作商店、口香糖动画、武器图标和整套 UI。资源缺陷写明，不额外批量生成补充角色。

交付后由程序任务 P03 接入；美术执行者不改 Unity 场景、配置或 `.meta`。
